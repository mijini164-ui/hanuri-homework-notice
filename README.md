# 한우리 수업도우미

한우리독서토론논술 선생님용 페이지예요. 어느 지부에서나 쓸 수 있어요. 반 명단 엑셀 하나로 세 가지를 만들어요.

| 탭 | 하는 일 |
|---|---|
| 수업계획서 | 학부모님께 보낼 달력형 월간 수업계획서 이미지 |
| 숙제 안내문 | 교재에 붙일 숙제 안내문 (A4 한 장에 두 개, PDF·사진) |
| 피드백 | 이번 달 수업 소개 + 학생별 피드백 이미지 (체크한 항목만 미리 만들어 둔 문장으로 들어가요) |

반 명단 엑셀은 한 탭에서 올리면 다른 탭에도 같이 들어가요.

## 파일

- `index.html` — 탭 세 개가 있는 첫 화면
- `plan.html`, `homework.html`, `feedback.html` — 각 탭 페이지
- `covers/` — 피드백 이미지에 들어가는 책 표지
- `forms/` — 엑셀 양식
- `scripts/check.mjs` — 올리기 전 점검. main에 올리면 GitHub Actions가 먼저 점검하고, 통과해야 GitHub Pages에 반영돼요.
